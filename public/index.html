YOUR TV, STEP BY STEP

Wireless debugging,
without the guesswork.

For an Android 14 TV, start with Wireless debugging if your TV offers it. This pairs your TV without a USB cable. Menu names and availability vary by manufacturer.

The screens below are recreations with example numbers. Always copy the numbers from your own TV.

  1. Turn on Wireless debugging

    Keep the TV and the computer running this app on the same home network. On the TV, open Settings → System → About and select Android TV OS build seven times to unlock developer options.

    Go back to System → Developer options → Wireless debugging. Turn it on and allow it on your home network if asked. Enabling USB debugging alone may not enable network access.

  2. Pair using the popup’s numbers

    Choose Pair device with pairing code on the TV. Leave this popup open while you fill in Pair a device in this app.

    1TV IP address
    192.168.1.42 — everything before the colon (:). Enter only this part in TV IP address.
    2Pairing port
    37099 — the number after the colon in this popup. Enter it in Pairing port.
    3Six-digit code
    123456 — the separate Wi-Fi pairing code. Enter all six digits in Six-digit code, then choose Pair TV.

    If pairing fails, open a fresh pairing popup and use its new code and port. The six-digit code is not the port.

  3. Connect using the main screen’s port

    The app tries to connect automatically after pairing. If it shows TV paired. One more step., close the TV’s pairing popup. Stay on the main Wireless debugging screen.

    1TV IP address
    192.168.1.42 — use the address before the colon again.
    2Connection port
    41113 — use the number after the colon on this main screen. Enter it in Connection port in this app, then choose Finish connecting or Connect to TV.
    Two screens. Two different ports.

    Pairing popup: 37099 → Pair TV
    Main screen: 41113 → Connect to TV

    Do not reuse the pairing port for connecting. Wireless debugging uses the ports shown on your TV; do not assume port 5555 will work.

  4. Install your app

    Wait for the green CONNECTED badge. Paste a direct APK link or choose a saved app link, then select Install on TV. Pairing alone does not enable installation; the TV must also be connected.

    Your TV is saved for next time. If its IP address or connection port changes, update the saved TV with Edit using the main Wireless debugging screen. You usually do not need a new pairing code while the authorization is still saved.

My TV doesn’t have Wireless debugging

Check its developer options for Network debugging or ADB debugging. Some older TVs use port 5555; use the port shown by your TV when available. Enable USB debugging as well if your model requires it, enter the TV’s IP and port, then approve the debugging prompt on the TV.

Some models require an initial USB setup to enable network access. This app cannot turn on a disabled debugging service remotely. Use your TV manufacturer’s instructions if these options are missing.

Still can’t connect?

Check the TV’s current IP and connection port, keep Wireless debugging on, and check for a prompt on the TV. Guest Wi-Fi, device isolation, firewalls, or a VPN can prevent a connection. A saved TV can need a new port after restarting or toggling Wireless debugging.
